# Design Documentation

UI mocks, class definitions, architecture diagrams, and design decisions that
span multiple tasks. Tasks update these as they go — they are living documents.

## File Naming

- `design-<name>.md` — e.g., `design-renderwindow.md`, `design-auth-flow.md`
- `mockup-<name>.md` — wireframes and UI sketches
- `class-<name>.hpp` — class definitions and interfaces
