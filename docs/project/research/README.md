# Research Notes

Task-agnostic dependency and pattern research. As tasks encounter new
dependencies or patterns during planning, create or update relevant research
notes here — don't duplicate research in individual task docs.

## How to Use

1. When a task needs to research a dependency/pattern, check if research already exists
2. If not, create `research-<topic>.md` with:
   - Source (authoritative documentation link)
   - Key findings
   - How to include/use in code
   - Version/commit pinned
3. Other tasks reference this file instead of re-researching
